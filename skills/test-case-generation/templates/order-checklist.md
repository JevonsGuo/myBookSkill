# 订单交易与状态流转检查清单 (Order Checklist)

- [ ] **1. 订单创建前置校验**：
  - 库存充足校验（防超卖）；
  - 价格有效性（防客户端篡改单价与总价，服务端必须强制重算）；
  - 限购数量（单人限购上限、单笔起购下限）。
- [ ] **2. 状态机严格正向流转**：
  - `待支付 -> 已支付 -> 履约中 -> 已完成`；
  - 严禁越步（如直接从“待支付”跨过支付接口跳转到“已完成”）；
  - 终态不可逆（“已取消”、“已完成”订单严禁再次变更为其他状态）。
- [ ] **3. 订单超时关单与库存回滚**：
  - 达到倒计时上限（如 15 分钟）系统定时任务自动关单并精准释放库存；
  - 用户在关单临界最后一秒支付的竞态条件排查。
- [ ] **4. 逆向流程（取消与售后）**：
  - 待支付状态主动取消；
  - 已支付未发货/未核销状态发起全额退款；
  - 履约中申请退款；
  - 售后完成后订单状态置为“已退款/已关闭”。
