# 账号认证与登录测试检查清单 (Login Checklist)

在针对账号登录、注册、找回密码或身份核验模块设计用例前，必须逐项勾选确认以下高频易漏场景：

- [ ] **1. 凭证输入与主流程**：
  - 手机号+密码/短信验证码正常流；
  - 邮箱/账号名登录正常流；
  - 第三方授权（微信、OAuth）首次登录与老用户绑定。
- [ ] **2. 验证码防刷与频控**：
  - 60 秒内重复点击获取拦截（前端倒计时 + 后端接口强校验）；
  - 同一手机号单日/单小时获取上限限制；
  - 同一 IP/设备号恶意批量请求拦截（风控人机滑块）；
  - 验证码有效期（如 5 分钟超时后使用拦截）；
  - 验证码一次性消费（成功验证后旧码立即作废，防二次提交）。
- [ ] **3. 凭证错误与防爆破**：
  - 连续输错密码/验证码达阈值（如连续 5 次）触发账号临时锁定或验证码提级；
  - 错误提示模糊化（提示“账号或密码错误”，防枚举用户名）。
- [ ] **4. Token 与会话生命周期**：
  - 登录成功返回 AccessToken 与 RefreshToken；
  - Token 自然过期后静默刷新；
  - RefreshToken 过期后强制重新登录；
  - 登出后旧 Token 立即加入黑名单或失效。
- [ ] **5. 多端登录与会话隔离**：
  - 同一账号多设备同时登录行为（互踢下线 vs 允许多端并存）；
  - 被踢下线端在发起新请求时给出友好提示并跳转登录页。
- [ ] **6. 弱网、重复提交与状态恢复**：
  - 点击登录后按钮置灰防重复提交；
  - 登录网络超时重试不会生成重复会话；
  - 登录后根据前置拦截 URL 正确重定向回原访问页面。
