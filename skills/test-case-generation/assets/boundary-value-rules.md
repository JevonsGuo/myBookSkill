# 边界值分析核心规则库 (Boundary Value Rules)

在分析输入参数与业务阈值时，强制采用以下**五点分析法（Min-1, Min, Normal, Max, Max+1）**：

## 一、 数值类型边界
- **整型与计数**：
  - 下限：0, 1, 最小值 - 1
  - 上限：上限值, 上限值 + 1
  - 极端：负数（-1）、超大整数（如溢出 INT32 或 INT64）
- **金额与浮点型**：
  - 零元（0.00）、极小值（0.01）、负数（-0.01，严格拦截反向扣费）
  - 精度越界：输入 3 位或更多小数（如 99.999），验证四舍五入或拦截规则
  - 极大金额：单笔最大限额（如 999,999,999.99）及超额测试

## 二、 文本与字符长度边界
- **长度极值**：
  - 允许最小长度（如 1 个字符）、空字符串（`""`）、纯空格（`"   "`）
  - 允许最大长度（如 20 个字符）、超长截断（21 个字符）
- **字符编码与特殊字符**：
  - Emoji 表情（测试 MySQL utf8mb4 是否支持，防乱码或异常宕机）
  - 脚本与注入字符：`<script>`, `' OR '1'='1`, `NULL`, `undefined`, `\n\r`
  - 前后空格过滤（如输入带有前后空格的账号，系统是否自动 Trim）

## 三、 集合与分页边界
- **列表与分页**：
  - 列表为空（0 条数据空状态展示）
  - 恰好 1 页满（如每页 10 条，数据库刚好 10 条，验证是否误出第 2 页）
  - 分页极值：`page=0`, `page=-1`, `pageSize=0`, `pageSize=10000`（防内存被打爆 OOM）
