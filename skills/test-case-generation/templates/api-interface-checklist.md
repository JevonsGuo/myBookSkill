# 技术接口与网络健壮性检查清单 (API Interface Checklist)

- [ ] **1. 入参校验与注入防护**：
  - 必填字段缺失响应 HTTP 400 及清晰错误码；
  - 字段类型不匹配（如字符串传给整数、布尔值传给数组）；
  - 特殊字符（SQL、XSS、换行符、Emoji表情、URL编码字符）。
- [ ] **2. 接口幂等性 (Idempotency)**：
  - POST/PUT 请求携带 `Idempotency-Key` 或业务唯一流水号；
  - 客户端网络重试时，服务端识别相同幂等键并直接返回前次快照结果。
- [ ] **3. 异常网络与中间件故障**：
  - 接口响应超时（如后端处理 10 秒后丢出 504 Gateway Timeout）；
  - 客户端断网连接重置（Connection Reset）；
  - 下游微服务熔断降级（返回降级兜底数据）。
- [ ] **4. 鉴权与水平越权 (BOLA/IDOR)**：
  - 未带 Token 或 Token 伪造响应 HTTP 401；
  - 传他人订单 ID/用户 ID 查询或修改（水平越权）响应 HTTP 403。
