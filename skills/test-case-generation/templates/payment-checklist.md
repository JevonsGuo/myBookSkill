# 支付结算与交易风控检查清单 (Payment Checklist)

在针对充值、支付、提现、退款、结算与对账模块设计用例前，必须逐项勾选确认以下关键场景：

- [ ] **1. 金额计算与精度安全**：
  - 零元支付、负数金额（防反向套现/逆向充值）；
  - 极大金额（如溢出上限值）拦截；
  - 涉及折扣、优惠券、多币种汇率时，必须使用高精度 Decimal（保留 2 位小数），验证四舍五入与尾项平账。
- [ ] **2. 并发扣款与防双花 (Double Spending)**：
  - 快速连点“立即支付”按钮，数据库必须有唯一支付单号或分布式锁，严禁重复扣款；
  - 多设备/多标签页同时发起支付同一笔订单；
  - 账户余额仅够付一笔时，并发提交两笔不同消费，只能成功一笔。
- [ ] **3. 支付状态机与时差 (TOCTOU)**：
  - 发起支付后，在收银台停留至订单超时，再完成支付的补单或退款流程；
  - 支付回调通知延迟到达（如支付成功5分钟后回调到达），状态流转平稳生效；
  - 支付渠道重复发送成功回调通知，系统严格幂等处理，不重复记账。
- [ ] **4. 逆向退款与结算冲正**：
  - 部分退款与全额退款计算；
  - 退款总额严格不得超过实付总额；
  - 重复点击退款按钮幂等防刷；
  - 结算对账（PMS vs 渠道/OTA）对账平账、单边账、退款单对账。
