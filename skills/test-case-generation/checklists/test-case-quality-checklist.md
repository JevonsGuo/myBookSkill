# 用例评审与交付验收自查清单 (Quality Checklist)

测试工程师在将用例提交评审或执行前，请逐项核对：

- [ ] **1. 覆盖率核验**：
  - [ ] 是否不仅包含了 Happy Path，且异常流用例占比达到 50% 以上？
  - [ ] 是否对所有关键数字输入字段都设计了边界值用例（Min, Max, Min-1, Max+1）？
- [ ] **2. 安全与资金核验**：
  - [ ] 凡涉及金额变动，是否均测试了负数、0 元与高并发重复提交？
  - [ ] 凡涉及状态变更，是否均测试了反向跳步（如终态再变更）？
  - [ ] 凡涉及对外接口，是否均验证了 Token 失效拦截与越权隔离？
- [ ] **3. 可执行性与规范性**：
  - [ ] 用例编号是否统一遵循 `TC-[MODULE]-[INDEX]` 格式？
  - [ ] 每条用例的测试步骤是否有序（1. 2. 3.），前置条件是否清晰？
  - [ ] 预期结果是否明确指出了具体提示语、错误码或状态机变化，无任何模糊措辞？
  - [ ] 是否在文末执行了 100 分制打分自检，且综合得分 ≥ 85 分？
