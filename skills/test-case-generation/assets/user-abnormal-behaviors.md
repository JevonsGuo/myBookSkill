# 用户异常行为与网络竞态库 (User Abnormal Behaviors)

用例设计时必须至少注入以下 2 项典型用户破坏性或弱网异常行为：

1. **按钮疯狂连击 (Double Click / Rapid Tapping)**：
   - 用户在 500 毫秒内连续点击 3 次“提交/支付/审核”按钮；
   - 验证：前端是否在第一次点击后置灰按钮，后端是否有分布式锁或幂等拦截，严禁插入多条重复记录。
2. **弱网延迟与断网重试 (High Latency & Offline Retry)**：
   - 接口响应延迟 5 秒（Simulated 3G/弱网）；
   - 用户在等待中途失去耐心，手动点击“重试”或重新提交；
   - 用户在发送请求瞬间关闭 Wi-Fi / 切飞行模式，验证是否有本地数据丢失或僵尸单据。
3. **页面长时间挂起超时 (Long Inactivity Timeout)**：
   - 停留在填写表单页面 30 分钟以上，Session 或 Token 自然过期后点击提交；
   - 验证：系统是否友好提示重新登录，登录后是否能暂存已填内容，防止心血丢失。
4. **多端并发与多窗口竞态 (Multi-tab Race Conditions)**：
   - 在同一个浏览器的两个标签页同时打开同一张审批单，Tab A 审批通过，Tab B 紧接着点击审批驳回；
   - 验证：后操作的 Tab 必须提示“单据状态已变更，请刷新”，严禁覆盖或脏写。
